# Add Pi platform adapter

Kata now recognizes [Pi](https://github.com/badlogic/pi-coding-agent) as a first-class coding platform. The `pi` adapter installs project skills into the Agent Skills standard directory `.agents/skills/<command>/SKILL.md`, which Pi discovers recursively. Global installs target the shared Agent Skills directory `~/.agents/skills/` — a native Pi global load path — so a single install is usable by Pi and any other Agent Skills-compatible harness; when `PI_CODING_AGENT_DIR` is set, global installs land in `$PI_CODING_AGENT_DIR/skills/` instead. Pi reads `AGENTS.md` as project/global context, so the Kata Agent Contract is honoured there; because Pi has no separate "rules" file concept, no platform rule file is installed. Pi has no declarative `PreToolUse` hook, so the adapter advertises `hooks: false` and the active-task write guard runs CLI/CI-only; model selection is delegated to the host `/model` command. Pi is included in delegation platform recommendations.
